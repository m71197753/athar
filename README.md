### العرض التقديمي وملفات التسليم

تم توليد `Athar-Platform-Presentation.pdf` بالتعديلات الحالية وتسليمه في مساحة العمل. ملف PowerPoint المتوفر تصدير سابق لا يتضمن بيانات الغلاف الجديدة. **لم يكتمل رفع PDF الحالي إلى GitHub:** رفضت واجهة رفع مرفقات الإصدار الطلب، لذلك لا يوجد رابط تنزيل منشور له في المستودع بعد.

توجد مسودة إصدار باسم **أثر | تسليم المشروع والعرض التقديمي** في [صفحة الإصدارات](https://github.com/m71197753/athar/releases)، يمكن لمالك المستودع إرفاق الملفين بها وإكمال نشرها. خطوات الإكمال وبصمات التحقق موضحة في [دليل العرض](docs/presentation/README.md).

المكان المخصص للملفات الكبيرة هو مرفقات **GitHub Release**، وليس سجل Git. مصدر الشرائح والصور المستخدمة موجود بالفعل في المستودع ويمكن تعديله.

## الخصائص الأساسية في الشفرة الحالية

### مساحة الطالب

- تسجيل الدخول والحسابات باستخدام Clerk، مع فصل مساحة الطالب عن الإدارة.
- لوحة رئيسية وملف شخصي.
- تسجيل الإنجازات وإرسال أدلتها للمراجعة بصلاحيات محددة.
- أقسام تعلم قابلة للتخصيص ودورات ووحدات ودروس ومواد مرئية.
- أكاديمية للمذاكرة والمواد والدروس والبحث والاختبارات والملفات.
- تعلم اللغات ومتابعة الممارسة والتقدم.
- السيرة الذاتية والمشاركة العامة عبر مسار مخصص.
- خطة مهنية ومهام وتذكيرات، ومساحة للخريجين.
- مساعد يعتمد على خدمات الذكاء الاصطناعي عند إعدادها.

### مساحة الإدارة

- إدارة المحتوى والأقسام والحسابات وإعدادات التجربة.
- مراجعة أدلة الطلاب وفق الصلاحيات.
- أدوات لإدارة اللغات والأكاديمية والإشعارات والإعلانات.
- سجلات ومتابعة لبعض عمليات الإدارة والملفات.

وجود الشفرة لا يغني عن اختبار الخدمات الفعلية في بيئة التشغيل. بعض الوظائف تتطلب إعداد قاعدة البيانات، والمصادقة، والتخزين، وخدمات الذكاء الاصطناعي.

## التقنيات

TypeScript، React، Vite، Tailwind CSS، Express، PostgreSQL، Drizzle ORM، Clerk، OpenAPI/Orval، وpnpm Workspaces.

ملفات الطلاب تعتمد على خدمة تخزين خارج Git؛ نقل المستودع لا ينقل ملفات التخزين أو سجلات قاعدة البيانات تلقائيًا.

## التشغيل والتطوير

### المتطلبات

- Node.js 24 وpnpm.
- PostgreSQL متاح للتطبيق.
- إعداد Clerk وخدمة التخزين والتكاملات المطلوبة.
- إعداد المتغيرات والأسرار من مدير الأسرار في بيئة الاستضافة، لا داخل المستودع.

```bash
pnpm install --frozen-lockfile
```

### الإعدادات المطلوبة

الجدول التالي يحتوي **أسماء فقط**؛ القيم لا تُرفق بالشفرة:

| الاسم | الاستخدام |
| --- | --- |
| `DATABASE_URL` | اتصال PostgreSQL |
| `CLERK_PUBLISHABLE_KEY` و`VITE_CLERK_PUBLISHABLE_KEY` | إعداد واجهة تسجيل الدخول |
| `CLERK_SECRET_KEY` | المصادقة على الخادم |
| `SESSION_SECRET` | سر الخادم لبعض الوظائف المساندة |
| `ADMIN_BOOTSTRAP_EMAILS` | تأسيس صلاحيات الإدارة لهويات موثقة |
| `DEFAULT_OBJECT_STORAGE_BUCKET_ID` | حاوية تخزين الملفات |
| `PRIVATE_OBJECT_DIR` و`PUBLIC_OBJECT_SEARCH_PATHS` | إعداد مسارات التخزين |
| `AI_INTEGRATIONS_OPENAI_API_KEY` و`AI_INTEGRATIONS_OPENAI_BASE_URL` | خدمات الذكاء الاصطناعي عند تفعيلها |
| `PORT` و`BASE_PATH` | منفذ ومسار كل واجهة؛ يضبطان لكل خدمة على حدة |

إعدادات Replit الحالية للخدمات موجودة في تعريف كل artifact. خارج Replit يلزم توفير بديل مناسب لتوجيه `/api`، وخدمة الملفات، وإعداد المصادقة؛ تشغيل الواجهة وحدها لا يشغّل المنصة كاملة.

### تشغيل الخدمات

شغّل كل أمر في عملية منفصلة. المنافذ التالية أمثلة متوافقة مع إعداد المشروع الحالي:

```bash
# الخادم — بعد تجهيز الأسرار
PORT=8080 pnpm --filter @workspace/api-server run dev

# واجهة المنصة
PORT=25693 BASE_PATH=/ pnpm --filter @workspace/athar-students run dev

# العرض التقديمي
PORT=22567 BASE_PATH=/athar-investor-presentation/ \
  pnpm --filter @workspace/athar-investor-presentation run dev
```

يمكن فتح العرض على `/athar-investor-presentation/`. وتتوفر مسارات `/slide1` وما بعدها داخل مسار العرض، ومسار `/allslides` للعرض المجمع.

### أوامر التطوير والتحقق

```bash
pnpm run typecheck
pnpm --filter @workspace/api-server run test:security
pnpm --filter @workspace/athar-investor-presentation run validate-slides

PORT=25693 BASE_PATH=/ \
  pnpm --filter @workspace/athar-students run build

PORT=22567 BASE_PATH=/athar-investor-presentation/ \
  pnpm --filter @workspace/athar-investor-presentation run build
```

هذه أوامر متاحة للتحقق؛ إدراجها هنا لا يعني أن جميعها نجحت في كل بيئة أو أنها تغطي المنصة بالكامل.

عند تغيير عقد API:

```bash
pnpm --filter @workspace/api-spec run codegen
```

عند إعداد مخطط قاعدة **تطوير** بعد مراجعة التغييرات:

```bash
pnpm --filter @workspace/db run push
```

لا تطبق تغييرات قاعدة البيانات على الإنتاج دون مراجعة وخطة استرجاع مناسبة، ولا تستخدم نسخة قاعدة الطلاب في التجارب.

## الأمان والخصوصية

- لا تُرفع الأسرار، أو ملفات `.env`، أو مفاتيح توقيع Android إلى Git.
- لا تُرفق ملفات الطلاب، أو سجلات قاعدة البيانات، أو جلسات الدخول بالإصدارات.
- إخفاء زر في الواجهة لا يكفي؛ الصلاحيات يجب فرضها على الخادم أيضًا.
- نشر سيرة عامة لا يعني أن جميع الأدلة والمرفقات أصبحت عامة.
- توافق قالب مع ATS لا يضمن قبول طلب توظيف.
- صلاحيات الإدارة يجب تأسيسها في كل بيئة على حدة.

## العرض والهوية

العرض الحالي يحتوي على **11 شريحة** وفق القائمة الحالية للشرائح، مع خلفيات وصور وأشكال مرتبطة بالمحتوى. الأسماء والشعارات المعروضة جزء من محتوى العرض المعتمد.

الشعارات والصور والمواد الخارجية تخضع لحقوق أصحابها؛ وجودها في المستودع لا يمنح حق إعادة ترخيصها. عرض شعاري Replit وNordpoints لا يعني وجود اعتماد أو شراكة رسمية.
