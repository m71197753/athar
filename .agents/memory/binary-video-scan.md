---
name: فحص ملفات الفيديو في CodeExecution
description: تجنب تجاوز مكدس التنفيذ عند فحص بيانات فيديو ثنائية.
---

عند فحص بيانات فيديو داخل CodeExecution، لا تمرر مصفوفة بايتات كبيرة دفعة واحدة إلى `String.fromCharCode(...)`. ابحث عن حقول ASCII باستخدام حلقات بايتية أو أجزاء صغيرة.

**Why:** فحص بيانات MP4 بحجم ميغابايت واحد تسبب في `RangeError: Maximum call stack size exceeded` عند توسيع المصفوفة كوسائط دالة.

**How to apply:** حوّل الحقول القصيرة الثابتة فقط إلى نص، مثل نوع صندوق MP4 ذي أربعة بايتات، وامسح بقية المحتوى بايتًا بايتًا.
