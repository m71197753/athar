# عرض منصة أثر

## ملفات التسليم وحالة الرفع

| الصيغة | الملف والحالة |
| --- | --- |
| PDF الحالي | `Athar-Platform-Presentation.pdf` — يتضمن غلاف Vibe Coding وأسماء المُنشئ والمشرف وشعار Replit؛ سُلّم في بطاقة تنزيل، ولم يُرفق على GitHub بعد |
| PowerPoint السابق | `Athar-Platform-Presentation.pptx` — تصدير أقدم يسبق إضافة بيانات الغلاف الجديدة، ولا يطابق PDF الحالي |
| بصمات الملفات | [`SHA256SUMS`](SHA256SUMS) — محفوظ في المستودع |

نجح تصدير PDF الحالي وفحص سلامته. خدمة رفع مرفقات GitHub رفضت الطلب. لم يُستعَض عن ذلك بإدخال ملف ثنائي كبير إلى سجل Git، ولم تُنشر روابط تحميل لا تعمل.

توجد مسودة إصدار غير منشورة باسم **أثر | تسليم المشروع والعرض التقديمي** ومعرّف إصدار مخطط `athar-delivery-2026-11-01`. المسودة تظهر لصاحب الصلاحية في [صفحة الإصدارات](https://github.com/m71197753/athar/releases)، ولا تعني وجود إصدار عام جاهز.

### إكمال إرفاق الملفين

1. نزّل ملف PDF الحالي من بطاقة التسليم في مساحة العمل. توجد نسخة محلية في `generated-artifacts/presentations/`، وهو مجلد مستبعد من Git عمدًا.
2. افتح مسودة الإصدار من حساب GitHub الذي يملك صلاحية إدارة المستودع.
3. أرفق PDF الحالي وملف `SHA256SUMS`، ثم انشر الإصدار بعد التأكد من ظهور المرفقات.
4. حدّث هذا الملف وREADME برابط PDF الفعلي بعد نجاح الرفع.

المصدر والصور اللازمة لبناء العرض موجودة في المستودع، بغض النظر عن إكمال رفع ملفات التصدير.

## المحتوى الحالي

تحتوي النسخة المصدرة على **11 شريحة** وفق القائمة الحالية:

1. الغلاف: أثر من التعلم إلى الإنجاز.
2. المشكلة: رحلة الطالب المتفرقة.
3. الحل: مساحة واحدة.
4. خطوات الحل داخل أثر.
5. الدورات والتعلم المنظم.
6. تعلم اللغات بالممارسة.
7. الإنجازات والخصوصية.
8. السيرة الذاتية.
9. الخطة المهنية.
10. الاستثمار في أثر.
11. الشكر والختام.

تستخدم الشرائح صورًا وأشكالًا مرتبطة بموضوع كل شريحة، مع خلفيات متغيرة وهوية لونية مشتركة. لا تتضمن أرقام أرباح أو بيانات سوق غير موثقة.

## تشغيل المصدر وفحصه

```bash
pnpm install --frozen-lockfile
pnpm --filter @workspace/athar-investor-presentation run validate-slides

PORT=22567 BASE_PATH=/athar-investor-presentation/ \
  pnpm --filter @workspace/athar-investor-presentation run dev
```

للبناء:

```bash
PORT=22567 BASE_PATH=/athar-investor-presentation/ \
  pnpm --filter @workspace/athar-investor-presentation run build
```

أُنتجت ملفات التسليم من العرض الحالي. عند تعديل المصدر، لا تتغير ملفات التصدير تلقائيًا؛ صدّر نسخة جديدة، وراجعها، وأرفقها بإصدار مناسب، وحدّث الروابط وبصمات الملفات.

## التحقق من سلامة التنزيل

تتوفر البصمات في [`SHA256SUMS`](SHA256SUMS). ضع الملف بجانب العرضين بعد تنزيلهما ثم شغّل:

```bash
sha256sum -c SHA256SUMS
```
